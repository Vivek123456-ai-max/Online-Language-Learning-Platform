# Online-Language-Learning-Platform
An interactive online language learning platform where learners can access lessons, take quizzes, track progress, and connect with other learners. Includes role-based dashboards for Admins, Instructors, and Learners to manage courses, content, feedback, and learning analytics.

<h3>LINK HERE :- <strong> https://codeverselearningplatform.netlify.app </strong></h3>

1. Admin

User Management: Users ke accounts create, update aur delete karna.

Content Management: Instructors ke lessons ko approve ya reject karna.

System Settings: Website ki settings manage karna.

Activity Monitoring: Website par users ki activities monitor karna.

<img width="1432" height="697" alt="Screenshot 2026-10-09 at 4 15 38 PM" src="https://github.com/user-attachments/assets/c0488251-1935-475d-a12b-a3fb35c80492" />

2. Instructor

Lesson Creation: Programming ya kisi bhi language ke lessons aur quizzes banana.

Provide Feedback: Learners ki performance par feedback dena.

Track Learner Progress: Students ki learning aur quiz scores check karna.

<img width="1409" height="697" alt="Screenshot 2026-10-09 at 4 16 24 PM" src="https://github.com/user-attachments/assets/774d67ce-7371-4947-bc7a-c36a969283ef" />

3. Learner

Lesson Participation: Lessons padhna aur quizzes solve karna.

Progress Tracking: Apni learning progress aur scores check karna.

Interact with Learners: Dusre students ke saath messages aur discussions karna.

Profile Management: Apna naam, email aur learning preferences update karna.
<img width="1425" height="697" alt="Screenshot 2026-10-09 at 4 14 58 PM" src="https://github.com/user-attachments/assets/e9ec9e43-04e1-431a-ac03-e9d42ec68ba3" />

4. Supabase PostgreSQL database to store user profiles, roles, programming courses, lessons, quizzes, enrollments, learning progress, feedback, and notifications with secure role-based access control.
